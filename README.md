# Retail Sales Data Analysis using Python (EDA)

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of retail sales data using Python. The main objective is to understand sales performance, customer behaviour, product demand and business trends through data analysis and visualisation.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Description
The dataset contains retail order information, including:
- Order details and dates
- Customer age and gender
- Product categories and sub-categories
- Sales, profit and discounts
- Region and city
- Payment modes
- Order status and customer ratings
- Shipping days

## Data Cleaning & Preprocessing
- Checked for missing values.
- Handled missing values using median and appropriate categories.
- Identified and removed duplicate records.
- Converted order dates into datetime format.
- Checked data types and dataset information.

## Exploratory Data Analysis

### Univariate Analysis
- Customer age distribution
- Gender distribution
- Orders by category and region
- Payment mode distribution
- Customer ratings
- Sales and profit distributions

### Bivariate Analysis
- Sales and profit by category
- Sales by region and customer type
- Sales by gender and payment mode
- Relationship between sales and profit
- Discount vs profit
- Shipping days and customer ratings

### Time-Based Analysis
- Yearly sales trends
- Yearly profit trends
- Monthly sales trends
- Top 10 cities by sales

## Key Insights
- Electronics is the strongest-performing product category.
- Regular customers contribute the highest sales and profit.
- UPI is the most preferred payment method.
- Female customers contribute slightly higher sales than male customers.
- Yearly sales and profit show a declining trend.
- Pune is the highest-performing city by sales.

## Conclusion
This analysis helped identify important retail sales trends, customer behaviour and business performance patterns. The findings can help businesses improve sales strategies, customer engagement and profitability.
